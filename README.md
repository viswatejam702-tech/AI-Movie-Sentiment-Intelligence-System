## 📌 Overview

AI Movie Sentiment Intelligence System is a production-ready Natural Language Processing application that analyzes movie reviews and predicts sentiment polarity using machine learning.

The platform leverages advanced text preprocessing, TF-IDF vectorization, and multiple Naive Bayes algorithms to classify reviews as Positive or Negative while providing confidence scores and interactive visual analytics.

This project demonstrates industry-standard practices in:

* Machine Learning
* Natural Language Processing
* Model Evaluation
* Data Visualization
* Streamlit Deployment
* Production-Ready Development

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI-Movie-Sentiment-System.git

cd AI-Movie-Sentiment-System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
